A nationwide directory of research opportunities — with universities and companies — built for community college students, who usually don't have a research office doing the legwork for them.

Live site: https://tristianpuga.github.io/the-stacks/

What it does
Directory of hand-verified research programs and internships, filterable by field, with real eligibility notes (many programs quietly exclude community college students — this only lists ones that don't)
Application help: a cold-email-to-a-PI template and a research interest statement structure, both built from what actually works based on advice from professors, program advisors, and students who've done this
Suggest a listing: a form so anyone can contribute a program that should be added
Why

Most research pipelines assume a student is already at a four-year school with an office doing outreach and application support for them. This project started because that assumption leaves out a huge number of students — this is the version for the rest of us.

Status

Actively growing. New listings get added as they're found. Suggestions are welcome through the form on the site.

Built with

Plain HTML/CSS/JS, hosted free on GitHub Pages. Suggestion form powered by Tally. Analytics via GoatCounter.
